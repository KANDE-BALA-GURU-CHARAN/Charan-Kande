# Mini Project Report

## Objective

The objective of this mini project collection is to improve practical Python programming skills through GUI applications, games, data handling, API usage, and event-driven programming.

## Software Used

- Language: Python
- GUI Library: Tkinter
- Database: SQLite for Attendance Management
- Data Files: JSON and CSV where needed
- API: Open-Meteo for weather information

## Project Descriptions

### 1. Alarm Clock

The Alarm Clock lets the user set a time in `HH:MM` or `HH:MM:SS` format. The program continuously checks the system time and plays an alert when the alarm time is reached.

Concepts used: time checking, loops, audio alerts, Tkinter labels and buttons.

### 2. Drawing Pad

The Drawing Pad allows the user to draw freely using mouse movement on a canvas. The user can select brush color, brush size, clear the canvas, and save the drawing as a PostScript file.

Concepts used: canvas widget, mouse events, buttons, sliders.

### 3. To-Do List and Reminders

The To-Do List app lets the user add, delete, and clear tasks. A reminder time can be added for a task, and the app displays an alert when the time is reached.

Concepts used: listbox, buttons, lists, JSON file storage, time checking.

### 4. Attendance Management System

The Attendance Management System stores student names and lets the user mark each student as Present or Absent for the current date. The records are stored in SQLite and can be exported as CSV.

Concepts used: tables, database storage, Tkinter Treeview, SQL operations.

### 5. Expense Tracker

The Expense Tracker records expenses with date, category, amount, and notes. It displays all expenses and calculates the total spending automatically.

Concepts used: lists, calculations, JSON file storage, table display.

### 6. Weather App

The Weather App accepts a city name, calls the Open-Meteo API, parses JSON data, and displays temperature, humidity, wind speed, and condition.

Concepts used: APIs, JSON parsing, URL requests, error handling.

### 7. Memory Card Matching Game

The Memory Game displays hidden cards. The player flips cards and tries to find matching pairs. The game tracks moves and matched pairs.

Concepts used: lists, buttons, state management, randomization.

### 8. Word Scramble Game

The Word Scramble Game shows a shuffled word. The player types the correct word to score points and move to the next round.

Concepts used: string manipulation, randomization, condition checking.

### 9. Typing Speed Test

The Typing Speed Test measures typing speed and accuracy while the user types a given sentence.

Concepts used: keyboard events, time measurement, string comparison.

### 10. Catch the Falling Objects

The player moves a basket to catch falling objects. The game uses canvas coordinates and animation loops.

Concepts used: coordinates, animation, collision detection, scoring.

### 11. Animal Identification Game

The game shows a simple generated animal image and asks the player to identify it from multiple-choice buttons.

Concepts used: images, buttons, random questions, scoring.

### 12. Puzzle Rearrangement Game

The Puzzle Rearrangement Game is a sliding puzzle where the user rearranges numbered blocks into the correct order.

Concepts used: grid layouts, logic building, list manipulation.

## Conclusion

This collection covers beginner Python concepts through practical applications. It includes GUI design, event handling, data storage, API integration, calculations, games, and problem-solving logic.
