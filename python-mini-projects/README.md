# Python Mini Projects

This repository contains 12 beginner-friendly Python mini projects based on the first-year Python programming concepts from the assignment.

## How to Run

Install Python 3.10 or later, then run any project directly:

```bash
python projects/01_alarm_clock/alarm_clock.py
```

You can also open the launcher:

```bash
python main.py
```

All projects use only Python standard library modules. No extra packages are required.

## Notes

- The Weather App uses the free Open-Meteo API and needs an internet connection.
- Data-based projects save small local files inside their own folders.
- These projects are written with clear code and comments so they can be explained in a viva or classroom review.
